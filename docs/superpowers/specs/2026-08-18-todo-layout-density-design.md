# Todo 列表排版密度调整设计

## 目标

在不改变 Todo 工作区功能、视觉语言和移动端交互的前提下，提高桌面端空间利用率：扩大页面主体与编辑抽屉宽度，并降低列表条目的垂直占用。

## 范围

- 桌面端页面主体最大宽度调整为 `1440px`。
- 桌面端筛选栏宽度由 `256px` 调整为 `272px`，让整体比例与更宽主体保持协调。
- 根任务条目的垂直内边距由 `16px` 调整为 `12px`。
- 子任务条目的垂直内边距由 `12px` 调整为 `10px`。
- 桌面端编辑抽屉调整为 `min(640px, 50vw)`。
- 移动端继续使用全宽底部抽屉。

## 保持不变

- 不修改 Todo 查询、创建、编辑、删除、状态切换和分页逻辑。
- 不修改颜色、字号、字段内容和列表信息层级。
- 保留交互控件现有的最小触控高度，列表变紧凑后仍满足键盘操作与可点击区域要求。
- 不改变移动端筛选 Dialog 和响应式断点。

## 实现位置

- `apps/web/src/index.css`：页面主体、工作区列宽、根任务与子任务的垂直间距。
- `apps/web/src/features/tasks/task-editor-panel.tsx`：桌面端编辑抽屉宽度。

## 验证

- 运行 `mise exec -- pnpm lint`。
- 运行 `mise exec -- pnpm typecheck`。
- 运行 `mise exec -- pnpm build`。
- 复核桌面端宽度、列表密度和抽屉宽度均符合设计，并确认移动端规则未被修改。
